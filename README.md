# Mary Rengel Portfolio

A simple portfolio website built with HTML, CSS, and JavaScript.

## Included files

- `index.html`
- `cv.html`
- `design-showcase.html`
- `contact-cards-demo.html`
- `css/style.css`
- `js/script.js`
- `assets/` and image preview files

## Getting started

1. Create a GitHub repository.
2. Add the remote:
   ```bash
git remote add origin https://github.com/<your-user>/<your-repo>.git
```
3. Push the first commit:
   ```bash
git push -u origin main
```
